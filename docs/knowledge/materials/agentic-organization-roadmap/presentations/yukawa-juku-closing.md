# エージェント組織の本質は、マネジメント

**背景・目的 → 問い → 判断 → 次の依頼**

::: {reveal}

- 背景・目的と、判断に必要な情報を渡す
- 何を確かめる質問かを決める
- 結果を `事実 / 推論 / 不足情報` に分ける
- 判断から次の依頼を `What / Why / How / Done` で渡す

:::

AIでは、**権限・禁止事項・人間承認・完了条件を、人より明示する。**[^microsoft][^google]

[^microsoft]: [Microsoft 2026 Work Trend Index, 2026-05-05](https://www.microsoft.com/en-us/worklab/work-trend-index/agents-human-agency-and-the-opportunity-for-every-organization)
[^google]: [Google Cloud, How agents can delegate better, 2026-08-22](https://cloud.google.com/blog/products/ai-machine-learning/how-agents-can-delegate-better)
