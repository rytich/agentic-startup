# エージェント組織導入ロードマップ

> **Evidence再調査中:** 2026-09-04に外部情報の選定方針を変更しました。既存claimは公開・更新から6か月未満の一次情報と独立したWeb・SNS評価を満たすまで、有効な根拠として使用しません。
